# Настройка прав бота для получения реальной статистики

## 📋 Что нужно для получения реальной статистики

Для получения **реальных данных** о просмотрах, реакциях и пересылках постов, бот должен иметь специальные права в канале.

## 🔧 Пошаговая настройка

### 1. Добавить бота в канал как администратора

1. Открой свой канал **grants.kz** в Telegram
2. Зайди в **Настройки канала** (Settings)
3. Выбери **Администраторы** (Administrators)
4. Нажми **Добавить администратора** (Add Administrator)
5. Найди своего бота (по username из BotFather)
6. Нажми **Добавить** (Add)

### 2. Настроить права бота

При добавлении бота как администратора, выдай следующие права:

✅ **Обязательные права:**
- ✅ **Post Messages** (Публикация сообщений)
- ✅ **Edit Messages** (Редактирование сообщений)
- ✅ **Delete Messages** (Удаление сообщений)

✅ **Для статистики:**
- ✅ **Anonymous Admin** (Анонимный админ) - НЕ включать! Иначе статистика не будет доступна
- ✅ **Manage Chat** - включить для доступа к аналитике

### 3. Проверить настройки канала

1. Убедись, что канал **публичный** или у бота есть полный доступ
2. Проверь, что бот может видеть историю сообщений

### 4. Получить ID канала

Если ты еще не получил ID канала:

1. Отправь любое сообщение в канал
2. Открой в браузере (замени `YOUR_BOT_TOKEN` на токен твоего бота):
   ```
   https://api.telegram.org/botYOUR_BOT_TOKEN/getUpdates
   ```
3. Найди в JSON-ответе:
   ```json
   "chat": {
     "id": -1001234567890,
     "title": "grants.kz",
     ...
   }
   ```
4. Скопируй ID (отрицательное число с минусом!)
5. Добавь его в `.env` файл:
   ```env
   CHANNEL_ID=-1001234567890
   ```

## 📊 Как работает сбор статистики

### Автоматический сбор

Когда бот публикует пост в канал:
1. Сохраняет `channel_id` и `message_id` в БД
2. Периодически обновляет статистику из Telegram
3. Сохраняет данные в поля:
   - `views_count` - количество просмотров
   - `reactions_count` - количество реакций
   - `forwards_count` - количество пересылок

### Ручное обновление статистики

Запусти скрипт для обновления статистики всех постов:

```bash
python update_stats.py
```

## ⚠️ Ограничения Telegram Bot API

### Что доступно:
- ✅ Количество реакций на пост
- ✅ Информация о пересылках (ограниченно)
- ✅ Общая информация о канале

### Что НЕ доступно через стандартный Bot API:
- ❌ Точное количество просмотров постов (только через Telegram Analytics API)
- ❌ Демографические данные подписчиков
- ❌ Детальная статистика переходов по ссылкам

### Решения:

1. **Для просмотров**:
   - Используй Telegram Analytics API (требует premium-аккаунт владельца канала)
   - Или используй приблизительные данные на основе реакций

2. **Для полной аналитики**:
   - Интеграция с официальной статистикой Telegram (через веб-версию)
   - Использование TDLib для доступа к расширенной статистике

## ❓ FAQ

**Q: Почему не видно просмотров?**
A: Telegram Bot API не предоставляет прямой доступ к просмотрам. Нужна интеграция с Telegram Analytics или использование TDLib.

**Q: Как часто обновлять статистику?**
A: Рекомендуется обновлять 1-2 раза в день. Слишком частые запросы могут привести к ограничениям.

**Q: Можно ли получить статистику старых постов?**
A: Да, если у них сохранены `channel_id` и `message_id` в БД, и бот был админом на момент публикации.
