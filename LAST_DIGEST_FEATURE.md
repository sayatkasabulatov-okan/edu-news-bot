# 📰 Новая функция: "Последний дайджест"

## 📝 Описание

Добавлена новая кнопка **"📰 Последний дайджест"** в главное меню бота. Эта функция позволяет модератору в любой момент просмотреть последний созданный дайджест и выполнить с ним необходимые действия.

### Зачем это нужно?

**Проблема:** Модератор может забыть опубликовать или запланировать дайджест после его получения. Сообщение с дайджестом может потеряться в истории чата.

**Решение:** Кнопка "Последний дайджест" всегда доступна в главном меню. Модератор может в любой момент:
- ✅ Посмотреть последний дайджест
- ✏️ Отредактировать его
- 📅 Запланировать публикацию
- 🚀 Опубликовать немедленно
- 🖼️ Сгенерировать новое изображение
- ❌ Отклонить дайджест

## 🔍 Как это работает

### Логика поиска дайджеста

При нажатии кнопки бот:

1. **Ищет последний дайджест** со статусами:
   - `draft` - Черновик
   - `approved` - Утверждён
   - `sent_to_moderator` - На модерации

2. **Сортирует по дате создания** (самый новый первый)

3. **Показывает дайджест** с информацией:
   - ID дайджеста
   - Статус
   - Дата создания
   - Полный текст
   - Кнопки действий

### Доступные действия

Кнопки зависят от статуса дайджеста:

#### Для статуса `draft` или `sent_to_moderator`:
```
┌─────────────────────────────────────┐
│   ✅ Утвердить  │   ❌ Отклонить    │
│  ✏️ Редактировать │  🔄 Пересоздать │
│  🖼️ Новое фото  │  📅 Запланировать │
└─────────────────────────────────────┘
```

#### Для статуса `approved`:
```
┌─────────────────────────────────────┐
│        🚀 Опубликовать сейчас       │
│           📅 Запланировать          │
│  ✏️ Редактировать │  🖼️ Новое фото  │
│            ❌ Отклонить             │
└─────────────────────────────────────┘
```

## 📊 Примеры использования

### Сценарий 1: Модератор забыл опубликовать

**Ситуация:** Утром пришёл дайджест, модератор прочитал, но забыл опубликовать. Вечером вспомнил.

**Решение:**
1. Открыть бота
2. Нажать **📰 Последний дайджест**
3. Увидеть дайджест со всеми кнопками
4. Нажать **🚀 Опубликовать сейчас** или **📅 Запланировать**

---

### Сценарий 2: Модератор хочет проверить, что было опубликовано

**Ситуация:** Модератор не помнит, какой дайджест был последним.

**Решение:**
1. Нажать **📰 Последний дайджест**
2. Посмотреть статус:
   - ✅ Утверждён - значит готов к публикации
   - 👀 На модерации - нужно проверить
   - 📝 Черновик - не обработан

---

### Сценарий 3: Нужно отредактировать опубликованный дайджест

**Ситуация:** Дайджест утверждён, но модератор заметил опечатку.

**Решение:**
1. Нажать **📰 Последний дайджест**
2. Нажать **✏️ Редактировать**
3. Внести правки
4. Опубликовать исправленную версию

    select(Digest)
    .where(Digest.status.in_(['draft', 'approved', 'sent_to_moderator']))
