# 🖼️ Исправление: Регенерация изображений

## 📝 Описание проблемы

### Симптомы:
- При нажатии кнопки **🖼️ Новое фото** первый раз - ошибка "не удалось сгенерировать изображение"
- При второй попытке - изображение генерируется
- При третьей попытке (изменить изображение снова) - бот перестаёт отвечать

### Ошибка в логах:
```
telegram.error.BadRequest: There is no text in the message to edit
```

### Причина:
Telegram различает два типа сообщений:
1. **Текстовые сообщения** - содержат только текст
2. **Сообщения с фото** - содержат фото + caption (подпись)

**Проблема:** Код использовал `query.edit_message_text()` для обоих типов сообщений.

- ✅ `edit_message_text()` работает только для текстовых сообщений
- ❌ `edit_message_text()` НЕ работает для сообщений с фото

**Для сообщений с фото** нужно использовать:
- `edit_message_caption()` - редактировать подпись
- Или удалить старое сообщение и отправить новое

---

## ✅ Решение

### 1. Создана вспомогательная функция `safe_edit_message()`

Эта функция автоматически определяет тип сообщения и использует правильный метод:

```python
async def safe_edit_message(query, text: str, reply_markup=None, parse_mode=None):
    """
    Safely edit a message regardless of whether it has a photo or not.
    """
    try:
        # Check if message has photo
        has_photo = query.message.photo is not None and len(query.message.photo) > 0

        if has_photo:
            # Edit caption for photo messages
            await query.edit_message_caption(
                caption=text,
                reply_markup=reply_markup,
                parse_mode=parse_mode
            )
        else:
            # Edit text for text-only messages
            await query.edit_message_text(
                text,
                reply_markup=reply_markup,
                parse_mode=parse_mode,
                disable_web_page_preview=True
            )
    except Exception as e:
        # If editing fails, delete and send new message
        logger.warning(f"Failed to edit message, trying delete+send: {e}")
        try:
            await query.message.delete()
        except:
            pass

        await query.message.chat.send_message(
            text=text,
            reply_markup=reply_markup,
            parse_mode=parse_mode
        )
```

### 2. Обновлена функция `handle_regenerate_image()`
