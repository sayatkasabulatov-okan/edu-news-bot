# 🎯 Система фильтрации релевантности контента

## 📝 Описание

Добавлена интеллектуальная система фильтрации, которая автоматически отбирает только статьи, связанные с **образованием, студентами и выпускниками**.

---

## ❗ Зачем это нужно?

### Проблема
Добавленные источники (Inform.kz, 24.kz, Zakon.kz и др.) публикуют новости на разные темы:
- ❌ Политика
- ❌ Спорт
- ❌ Развлечения
- ❌ Криминал
- ✅ **Образование** ← только это нам нужно!

### Решение
Система анализирует каждую статью по **ключевым словам** и пропускает только релевантные материалы про:
- ✅ Студентов и выпускников
- ✅ Образование за рубежом
- ✅ Гранты и стипендии
- ✅ Стажировки и программы обмена
- ✅ Университеты и поступление
- ✅ Экзамены (IELTS, TOEFL и др.)

---

## 🔍 Как это работает

### 1. Проверка при сборе статей

Когда бот собирает новости, каждая статья проходит через фильтр:

```python
# Пример из GenericParser
relevance_result = relevance_checker.check_relevance(title, content)
if not relevance_result['is_relevant']:
    # Статья отклоняется
    logger.debug(f"Skipping irrelevant article: {title}")
    continue
```

### 2. Двойная проверка

Фильтр работает в **два этапа**:

1. **По заголовку** - быстрая проверка при сборе списка статей
2. **По полному контенту** - детальная проверка после загрузки статьи

### 3. Алгоритм оценки

```
Релевантность =
    ✅ Количество релевантных ключевых слов
    ❌ - Количество нерелевантных слов

Если релевантных слов ≥ 1 → Статья проходит
Если нерелевантных >> релевантных → Статья отклоняется
```

## ⚙️ Настройки фильтра

### Параметры (в [src/utils/relevance_checker.py](src/utils/relevance_checker.py))

```python
# Минимальное количество релевантных слов
MIN_RELEVANT_MATCHES = 1  # Статья должна содержать хотя бы 1 релевантное слово

# Максимальное количество нерелевантных слов (с контекстом)
MAX_IRRELEVANT_MATCHES = 3  # До 3-х исключений, если есть релевантные слова
```

### Как работают правила:

```python
if relevant_words >= 1:
    if irrelevant_words > 3 AND irrelevant_words > relevant_words * 2:
        # Отклонить (слишком много мусора)
    else:
        # Принять (есть образовательный контекст)
else:
    # Отклонить (нет релевантных слов)
```
